A notebook, not another cloud.

KinKeep is a small program that runs where you choose. It stores the household notebook in a local SQLite file and offers one MCP endpoint for a compatible assistant or app.

A deliberate boundary

Private by design. Not magic.

KinKeep is self-hosted; you choose where its SQLite file lives. Network access still needs careful setup. The server requires separate read and write bearer tokens, and network traffic should use HTTPS.

This project is a prototype, not a medical device, and the current credentials are household-wide—not individual family identities.

What is true today

  • Read access and write access use different, randomly generated tokens.
  • Sessions, requests and request bodies have configurable resource limits.
  • Origin checks add a browser safeguard; they are not sign-in.
  • Account linking uses OAuth 2.1 with PKCE (S256). It has not had an independent security review, and Amazon's Alexa+ onboarding is still gated.
Use synthetic demo data. Do not put real household health information on an exposed server.
